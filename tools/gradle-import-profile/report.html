Measurement conditions

@@CACHE_NOTE@@

Cache snapshot: @@SNAPSHOT@@. Dependency mode @@DEPENDENCIES@@: cached imports run offline with seeded downloads; download mode clears the dependency artifact cache.

IDEA, its project model, OS filesystem caches, installed SDKs, and provisioned tools remain warm. Gradle and compiler JVMs start fresh. Setup, profiler attachment, recorder shutdown and catch-up indexing are outside the measured interval.

Deleting only project caches, or changing scripts to invalidate Kotlin DSL caches, can retain global transforms, generated jars and build outputs. Compare timings only after matching these reset conditions and checking the raw task outcomes.

Other JVMs observed: @@CONTENTION@@. Their presence is recorded; this is not a contention correction. Instrumentation: @@INSTRUMENTATION@@. No overhead estimate is subtracted.
